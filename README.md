# Datenlabor: Bit, Byte und Einheiten

Interaktives Lernlabor für Informatik Klasse 7 (eine Unterrichtsstunde, 45 min):
Aufwärmen 8 Bit, Bit und Byte, Einheitentreppe mit Binärpräfixen, Speicher-Check im Datei-Explorer, Exit-Check, Profi-Zone.
Dazu gehört ein Arbeitsblatt mit drei Lückenkästen.

## Veröffentlichen mit GitHub Pages

1. Auf github.com ein neues öffentliches Repository anlegen, z. B. `bitbyte`.
2. **Add file → Upload files**: `index.html`, `README.md` und `.nojekyll` hochladen, **Commit changes**.
3. **Settings → Pages**: Source „Deploy from a branch“, Branch **main**, Ordner **/ (root)**, **Save**.
4. Nach ein bis zwei Minuten erreichbar unter `https://BENUTZERNAME.github.io/bitbyte/`.

## Raum für die Klasse

1. Lehrkraft-Ansicht öffnen (bewusst versteckt):
   - Adresse mit `#lehrkraft` am Ende aufrufen, z. B. `https://BENUTZERNAME.github.io/bitbyte/#lehrkraft` (am besten als Lesezeichen speichern), oder
   - im Startfenster **doppelt auf den Roboter Bitty** klicken, oder
   - im Labor **doppelt auf die kleine Versionsnummer „v2.1“** unten links klicken.
2. **Codes erzeugen** (z. B. 28 Stück) und die Zuordnung Code → Kind nur bei sich notieren.
3. **Raum öffnen**, Raumcode an die Tafel schreiben. **Diese Seite muss geöffnet bleiben**, solange die Klasse arbeitet.
4. Die Kinder geben Raumcode und ihren persönlichen Code ein.
5. Unter **Lernstand** erscheinen live Fortschritt, Selbstchecks (S1–S7) und die Lernziele aus dem Exit-Check (L1–L4). **Als Tabelle kopieren** liefert eine CSV für Excel.

Technik und Datenschutz: Die Verbindung läuft direkt von Browser zu Browser (WebRTC über PeerJS). Der öffentliche PeerJS-Vermittlungsserver stellt nur die Verbindung her; die Ergebnisse werden ausschließlich im Browser der Lehrkraft gespeichert. Es werden keine Namen übertragen, nur die Codes.
Hinweis: Manche Schulnetze blockieren WebRTC. Dann bitte vorher mit zwei Geräten testen. Notfalls können die Kinder „Ohne Raum üben“ wählen.
